# MSP 1.3P — индекс доказательств

**Относится к:** ТЗ MSP 1.3P §27, §28

Для каждого из 23 критериев указано, чем он подтверждается и откуда берётся статус. Статусы `PASS`, `PASS_WITH_WARNING`, `FAIL`,
`NOT_TESTED`; `SKIPPED` не является `PASS`. Статус критериев вычисляется платформой (`GET /api/v1/pilot/evidence`, поле `criteria`) и
**не назначается вручную**. Само подтверждение среды — запись с ссылкой на документ в эксплуатационном хранилище; в репозиторий
документы, письма, адреса и ключи не кладутся.

Колонка «Состояние в репозитории» — то, что можно сказать без корпоративной среды.

|--:|---|---|---|---|

## Артефакты

| Артефакт | Источник |
|---|---|
| Агрегированные метрики и критерии | `GET /api/v1/pilot/evidence` |
| Решения по фазам (роли и время подтверждений) | там же, поле `decisions` |
| Остановки (причина, область, разбор) | `GET /api/v1/pilot/stops` |
| Готовность контролей | `GET /api/v1/pilot/readiness`, раздел `controls` |
| Проверка резервной копии ключа карантина | `scripts/quarantine_key_check.py --json` |
| Политика, контрольные суммы и узлы | `GET /api/v1/enforcement/safety`, `/enforcement/policies/current` |
| Решения принуждения с просмотром | `GET /api/v1/enforcement/decisions` |
| Журнал аудита | действия `pilot.*` и `enforcement.*` |

Хеш архива доказательств (`EVIDENCE_ARCHIVE_SHA256`) считает организация по своему архиву в эксплуатационном хранилище.
