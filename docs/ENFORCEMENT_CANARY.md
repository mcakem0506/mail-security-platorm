# Канарейка: как включить принуждение для малой области

**Относится к:** ТЗ MSP 1.3 §17, §18, §24, §25, §72, §83, §84

Канарейка — первое состояние, в котором контроль действует на почту. Она всегда ограничена областью и всегда согласуется двумя
людьми. Пилот — следующий шаг, он требует выборки реального потока ([ENFORCEMENT_PILOT_PLAN.md](ENFORCEMENT_PILOT_PLAN.md)).

## Порядок

1. **Проверка готовности.** Консоль → «Принуждение» → «Контроли»: статус готовности и причины. `BLOCKED_BY_GAP` обойти нельзя.
   Для `SPAM_REJECT` нужны: аудит действий сканера без неизвестных источников, просмотренная выборка кандидатов на отказ,
   подтверждённые тесты и отказоустойчивость ([ENFORCEMENT_READINESS.md](ENFORCEMENT_READINESS.md)).
2. **Запрос** (право `enforcement:canary`): область (получатели, группы, домены отправителей, CIDR, пилотный домен, процент),
   пороги, обоснование ≥ 10 символов, цель отката. Пустая область запрещена.
3. **Согласование** другим человеком с тем же правом. Готовность проверяется заново. Результат — новая подписанная версия политики.
4. **Распространение.** Узлы забирают политику (опрос раз в 30 с), проверяют подпись и применяют. Контрольная сумма узла видна на
   панели «Безопасность»; расхождение — тревога `POLICY_DRIFT`.
5. **Наблюдение.** Решения со свидетельствами, версией политики и разбором аналитика («верно» / «ложное» / «критическое»).
   Каждый применённый отказ — событие аудита.

## Что происходит с почтой

| Получатель | Письмо с высокой оценкой спама | Законное письмо |
|---|---|---|
| в области канарейки (все получатели письма) | `554 5.7.1` общий отказ в исходной сессии SMTP | доставляется |
| вне области | доставляется; предложение «отказать» записано, применено «только наблюдение» | доставляется |
| часть получателей в области | доставляется целиком (разрушительное действие только для письма, где в области все) | доставляется |

Ответ SMTP не содержит оценок, правил и топологии. Повтор того же письма даёт то же решение (хэш адреса получателя).

## Проверено на стенде

`tests/enforcement/test_spam_canary.py`: наблюдение до включения; готовность и два человека; общий отказ в области; свидетельства,
версия политики и аудит каждого отказа; вне области только предложение; законное письмо; несколько получателей; повтор;
отказ службы принуждения не останавливает почту; общий выключатель; перебой панели; локальный обход; откат к прежней контрольной сумме.
Лабораторная выборка допускает только канарейку и только при `MSP_ENFORCEMENT_LAB_MODE=true`.

## Выход из канарейки

Пауза (`enforcement:pause`), откат ([ENFORCEMENT_ROLLBACK.md](ENFORCEMENT_ROLLBACK.md)) или общий выключатель
([ENFORCEMENT_KILL_SWITCH.md](ENFORCEMENT_KILL_SWITCH.md)). Критическое ложное срабатывание останавливает контроль само
([FALSE_POSITIVE_EMERGENCY.md](FALSE_POSITIVE_EMERGENCY.md)).
